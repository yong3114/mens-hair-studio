MEN'S HAIR STUDIO V2 - GITHUB ACTIONS SECRETS
=============================================

GitHub Repo -> Settings -> Secrets and variables -> Actions -> New repository secret

Create these 3 secrets exactly:

1) Name:
VITE_SUPABASE_URL
Value:
Your Supabase Project URL
Example: https://xxxxxxxxxxxx.supabase.co

2) Name:
VITE_SUPABASE_ANON_KEY
Value:
Your Supabase Publishable / anon key
DO NOT use service_role / secret key.

3) Name:
VITE_GOOGLE_MAPS_API_KEY
Value:
Your Google Maps Platform browser API key
This is used by Places Autocomplete / Maps in the frontend.
Restrict the key by HTTP referrer when the GitHub Pages URL is known.

IMPORTANT
---------
- Never commit .env to GitHub.
- Never put Supabase service_role key in this app.
- Never put database password in GitHub.
- The Supabase publishable/anon key and browser Google Maps key are frontend credentials; security still depends on Supabase RLS and Google API key restrictions.

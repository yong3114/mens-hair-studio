# V2.2 Review & Roadmap

## 已经处理
- Before / After tabs 排版
- Started service 在 Calendar 显示 Continue，不再像未开始一样
- Service 管理 in_progress / completed 状态
- 手机换页面自动回顶部
- 手机/浏览器 Back 使用网页内部 history
- Customer Portal UI Preview
- Mobile spacing / tabs / actions / calendar controls polish

## 建议下一轮优先级

### P1 — 稳定营业流程
1. Service 与 Appointment 更强的一对一状态提示。
2. Booking / Service / Payment 操作统一 Toast success/error，不使用 browser alert/confirm。
3. Unsaved changes 提醒，避免手机误按 Back 丢表单。
4. 所有关键列表加入 loading skeleton / retry error state。

### P2 — Customer Portal 正式化
1. 顾客独立 Login。
2. 顾客只能读取自己的资料（RLS）。
3. Book / reschedule request，而不是直接修改内部 Calendar。
4. 查看下一次预约、Hair System、Service History、Account Credit、Payments、Before/After。
5. 可选 WhatsApp OTP / magic link。

### P3 — Accounts / Finance
目前 Payments 是营业收款管理，不是完整会计系统。
要做成真正 Business Accounts，建议增加：
- Expenses / Supplier expenses
- Categories / Chart of Accounts（简化版）
- Daily cash closing
- Income vs expense
- Profit & Loss
- Cash flow
- Outstanding receivables
- Deposit liability / customer credit liability
- Refund tracking
- Bank reconciliation
- Invoice / Receipt numbering
- CSV / accountant export

### P4 — 运营效率
- Appointment reminders
- Maintenance WhatsApp follow-up
- Customer tags
- Lead follow-up templates
- Hair System replacement lifecycle
- Dashboard period filters

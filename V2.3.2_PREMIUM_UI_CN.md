# V2.3.2 Premium UI / Interaction Polish

这版不改数据库，也不改 Hair System 主流程。
重点是把现有功能做得更像正式 App：更顺、更高级、更舒服，尤其是手机触控体验。

## 已优化

- 页面切换加入轻量 enter motion
- Modal / Drawer / Bottom Sheet / Notification 加入更自然的出现动画
- 按钮 hover / press / focus feedback 重新统一
- 手机 touch 按压反馈更明显，但不过度弹跳
- Sidebar active 状态、Navigation 视觉层次优化
- Bottom Navigation active indicator / press feedback 优化
- Input / Select / Textarea focus ring、hover、尺寸统一
- Cards / tables / quick actions 重新统一 hover / press / shadow
- Calendar event micro-interaction 优化
- Notification popover 阴影、出现方式、未读状态优化
- Mobile header / bottom nav 玻璃质感与 safe-area 处理加强
- Mobile modal / drawer 改成更像 native app bottom sheet
- Scrollbar、selection、loading state、focus-visible 优化
- 支持 prefers-reduced-motion，无障碍用户可关闭大部分 motion

## 不需要做的事

- 不需要跑 SQL
- 不需要改 Supabase
- 不需要改 Google Maps API
- 不需要改 GitHub Secrets

只要覆盖代码后 git push 即可。

# V2.3 业务逻辑地图

## Lead

还没成交的人都留在 Leads。

可只有：
- WhatsApp display name
- username
- area
- source

不需要真实姓名，不需要电话号码。

## Consultation

Consultation 是 Appointment，不是 Service。

Start Consultation 后记录：
- Hair concern
- Coverage area
- Colour
- Density
- Hairline
- Lifestyle
- Budget
- Ah Bi recommendation

最后必须选择：
- Signed
- Follow up
- Not signed

## Signed

只有 Signed 后才创建 Client。

同时记录：
- Stock / Custom
- Hair system specs
- Quoted price
- Discount
- Final price
- Deposit
- Balance
- Ready stock reserve / expected ready date

## Installation

Signed Client 的下一步是 Installation，不是 Maintenance。

New System Installation 完成后：
- Client → Active Client
- Deal → Installed
- Reserved Hair System → Installed
- 才开始 maintenance cycle

## Active Client

Active Client 才有：
- Maintenance
- Cleaning + Rebond
- Hairline Touch-up
- Haircut / Adjustment
- Next maintenance date

## Staff Job

Appointment Assigned To Ah Bi：
- Ah Bi Dashboard → My Jobs
- In-app notification

V2.5 再接：
- WhatsApp staff notification
- Email staff notification
- Customer reminder automation
